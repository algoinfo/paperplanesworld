How to run a fair paper airplane flight test 怎样公平地测试纸飞机飞行

A tape measure, a starting line and ten throws: how to find out whether a change really helped, with a printable log and a worked scoring example. 一把卷尺、一条起飞线、十次投掷：如何判断改动是否真的有效，附可抄写的飞行日志与中位数计分示例。

Paper Planes World · 3 min read 纸飞机机库 · 约 3 分钟阅读

In short: 一句话： change one thing, alternate the two versions (A, B, A, B…), throw each at least five times from the same line, and compare the middle result, not the best one. 一次只改一件事，两种版本交替投掷（A、B、A、B…），各自至少五次、同一起飞线，比较中间成绩，而不是最好的那一次。

One lucky throw feels great and proves almost nothing. Hand launches swing widely, so a single flight can make a weaker plane look stronger. A fair test needs almost no gear: tape for a release line, a measuring tape or careful paces, and a pencil. Then you can say how often the change helped — for example in eight throws out of ten — instead of guessing from memory.

一次幸运投掷很爽，但几乎说明不了什么。徒手投掷波动很大，单独一次飞行会让较差的飞机看起来更好。公平测试几乎不需要设备：胶带标起飞线、卷尺或步测、一支笔。这样你可以说改动在十次里赢了几次，而不是凭印象猜。

Ask one question 只问一个问题

Good questions stay small and concrete:

好问题要小、要具体：

  • Does bending the trailing edges up 1 mm stop this Basic Dart from diving?
  • 把后缘上折 1 毫米，能不能让这架 Basic Dart 不再栽头？
  • Does Condor travel farther on printer paper or notebook paper?
  • Condor 用打印纸飞得更远，还是用笔记本纸？
  • Does a soft release keep Lock-Bottom straighter than a hard snap?
  • 轻柔出手是否比猛掷更能让 Lock-Bottom 飞直？

Change exactly one variable between version A and version B. If you swap the paper, the trim, and the throw together, you only learn that the whole package was better — not which part did the work.

A 与 B 之间只改一个变量。如果同时换纸、改微调、改投掷方式，你只能知道整套组合更好，却分不清是哪一项起了作用。

Set up the lane 布置试飞跑道

  1. Use a clear indoor space without fans or open windows. A hallway or gym works well.
  2. 选没有风扇、不开窗的室内空地。走廊或体育馆最合适。
  3. Tape a release line. The same person throws every time, from the same height.
  4. 用胶带标出起飞线。始终由同一个人、从同一高度出手。
  5. Choose one score before you begin: forward distance, hang time, or distance from a target.
  6. 开始前先选定一个得分项：前进距离、滞空时间，或离目标的距离。
  7. Count the landing as the first touch on the floor. Sliding after impact does not count.
  8. 以首次触地为落点。落地后的滑行不算。
  9. Measure forward distance from the line along the lane. Note sideways drift on its own.
  10. 从起飞线沿跑道量前进距离，侧偏另外记下。

Outside, even a light breeze can outweigh your tweak. If you must test outdoors, write down the wind and fly both versions in the same conditions.

户外哪怕微风，影响也可能大过你的改动。若必须在室外测，记下风向风力，并让两种版本在同一条件下投掷。

Alternate the throws 交替投掷

Call the original plane A and the changed plane B. Throw A, then B, then A again, until each has at least five throws. Alternating spreads warm-up, fatigue, and tiny room changes across both versions instead of dumping them onto one side.

原版叫 A，改版叫 B。按 A、B、A… 交替投，直到各自至少五次。交替可以把热身、疲劳和室内细微变化摊到两边，而不是全堆在一侧。

Check the plane after every landing. A bent nose or a half-open wing changes the test; note when it happens. If the damage is serious, fold two fresh matching planes and restart the set.

每次落地后检查飞机。机头压弯或机翼半开都会改结果，发生时写下来。损伤严重就折两架新的配对机，整组重来。

Score it with the median 用中位数计分

Sort each plane’s distances and take the middle value: the median. It shrugs off the one lucky toss and the one fumbled release. Here is an illustrative example made to show the arithmetic, not a real trial:

把每架飞机的距离排序，取中间那个值：中位数。它不受一次走运或一次失手影响。下面是为演示算法而编的例子，不是真实试验：

Worked example (illustrative numbers) 演算示例（虚构数字）
Five distances, sorted五次距离（已排序） Median中位数
A (flat edges)A（后缘平） 3.1, 3.4, 3.8, 4.0, 7.2 m 3.8 m
B (edges up 1 mm)B（后缘上折 1 mm） 4.1, 4.4, 4.5, 4.9, 5.0 m 4.5 m

A owns the longest single throw, yet B wins on a typical throw and stays more consistent: its flights sit within about a metre of each other. That consistency is worth recording. For a target test, the smaller median miss wins.

A 有最远的单次，但 B 在典型投掷上更好，也更稳定：几次飞行都挤在大约一米范围内。这种稳定性值得记下。若测打靶，中位数偏离越小越好。

Write a conclusion that fits the evidence 结论要贴合证据

State exactly what you tested: “For this Basic Dart, on printer paper, thrown indoors by me, bending the trailing edges up 1 mm gave a longer median distance and fewer dives.” That is a useful result. “Bent edges make planes fly farther” is more than you showed. To see whether it holds more widely, repeat with fresh planes, another thrower, or another design.

把测试条件写清楚：“对我这架 Basic Dart，用打印纸、在室内由我投掷，后缘上折 1 毫米提高了中位距离并减少了栽头。”这才是有用的结论。“上折后缘让飞机飞得更远”超出了你证明的范围。想知道是否更普遍，就换新飞机、换投掷者或换机型再测。

You can run the same comparison in the site’s 3D test flight. Keep those numbers in a separate column: a simulated throw is perfectly repeatable and its paper never wrinkles, so it answers a slightly different question.

同一对比也可以在本站的 3D 试飞里做。把模拟数据单独一列：模拟投掷完全可重复、纸也不会皱，回答的是略有不同的问题。
